                              STEP-BY-STEP BUILD
================================================================================

OPTION 1: BUILD ON WINDOWS/MAC/LINUX (RECOMMENDED)
────────────────────────────────────────────────────

1. Copy the KineCut folder to your computer:
   - Windows: C:\Users\YourName\KineCut
   - Mac: ~/KineCut
   - Linux: ~/KineCut

2. Open Android Studio
   - File → Open → Select KineCut folder
   - Wait 5-10 minutes for Gradle sync

3. Build APK
   - Build → Build Bundle(s)/APK(s) → Build APK(s)
   - OR press Ctrl+Shift+A and search "Build APK"
   - APK will be generated in: app/build/outputs/apk/debug/app-debug.apk

4. Install
   - Connect Android device (min API 24, preferably ARM64)
   - Click Run → Run 'app'
   - OR use: adb install app/build/outputs/apk/debug/app-debug.apk

⚠️  ANDROID STUDIO REQUIRED

================================================================================
                          TROUBLESHOOTING
================================================================================

GRADLE SYNC FAILS:
  → Check internet connection
  → Delete .gradle folder and retry
  → Update Android Studio

BUILD FAILS: "SDK not found"
  → Open Android Studio → Tools → SDK Manager
  → Install API level 35, Build Tools 35.x

BUILD FAILS: "Gradle Daemon Timeout"
  → gradle.properties: org.gradle.jvmargs=-Xmx4g
  → Restart Android Studio

APP CRASHES: "API key error"
  → Add Groq/Gemini keys in Settings
  → Or disable AI features in code

APK WON'T INSTALL: "Incompatible"
  → Check: adb shell getprop ro.product.cpu.abilist (need arm64-v8a)
  → Uninstall old version first: adb uninstall com.kinecut.app
